# Math & Symbol Formatting Rules

- Do not use LaTeX math delimiters or macros (e.g., `$ ... $`, `$$ ... $$`, `\ge`, `\le`, `\implies`, `\times`, `\pm`, `\alpha`, `\beta`).
- Always format mathematical and logical expressions using standard Unicode symbols or inline code/plain text.
  - Examples:
    - Instead of `($S \ge 0.95 \implies p \le 0.05$)`, write `(S ≥ 0.95 ⇒ p ≤ 0.05)`.
    - Instead of `$\alpha = 0.05$`, write `α = 0.05`.
    - Instead of `$a \times b \pm c$`, write `a × b ± c`.
    - Instead of `$x \ne y$`, write `x ≠ y`.
