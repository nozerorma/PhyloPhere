The column names of PrimateAI-3D.hg19.txt.gz or PrimateAI-3D.hg38.txt.gz are 
chr : chr of this missense variant on either hg19 or hg38   
pos :  base position of this missense variant on either hg19 or hg38
non_flipped_ref : reference allele 
non_flipped_alt : alternative allele  
gene_name : Ensemble ID of the canonical transcript the variant is located in
change_position_1based: indicate the amino acid position where the missense variant occur, e.g., "2" means the variant is present at the second amino acid in the protein
ref_aa : reference amino acid of this missense variant
alt_aa : alternative amino acid of this missense variant
score_PAI3D : PrimateAI-3D score of this missense variant
percentile_PAI3D: the genomewide percentile of PrimateAI-3D score of this missense variant
refseq: RefSeq ID of the canonical transcript the variant is located in
prediction: indicate the missense variant is benign or pathogenic according to gene-specific PrimateAI-3D cutoff


Note that PrimateAI-3D.hg19.txt.gz is generated by lifting-over PrimateAI-3D.hg38.txt.gz from hg38 to hg19.
